# SEO: The site found, shared and read by agents

The docs site says what slipbox is to whoever reaches it without opening it: a search engine's result, a link shared
in a chat, an agent reading the docs. Every page's title and the docs home's description say that with slipbox you
read, review and edit what your coding agent writes, in your terminal, the line slipbox now describes itself with
everywhere; a link to any page, or to the site's root, shows slipbox's picture; the docs are served as `llms.txt` and
in full as `llms-full.txt`; and the site's build fails if any of it goes missing. From issue #66.
