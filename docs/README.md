# slipbox documentation

slipbox is a terminal app for reading and writing Markdown notes. You read and edit in its TUI; agents and scripts
use its command line; both work on the same plain files, so neither ever sees a stale copy.

## Start here

1. [Installing slipbox](guides/install.md): what you need, installing (a release, a preview, or from source),
   upgrading and removing it.
2. [Getting started](guides/getting-started.md): a first session in a folder of your own notes.

## Guides

Each walks through one job from start to end.

- [Working with agents](guides/agents.md): slipbox beside a coding agent, sharing the same files.
- [Code and git](guides/code-and-git.md): a repository's code, its problems and its changes.
- [Coming from Obsidian or zk](guides/from-obsidian-or-zk.md): opening a vault or a notebook as it is.
- [Exporting notes](guides/exporting.md): a note, or several, as Word, PDF, a web page, an e-book or Markdown.
- [Making it yours](guides/making-it-yours.md): themes, keys and settings.

## The manual

Everything slipbox does, a chapter for each part.

- [How slipbox works](manual/how-it-works.md): the ideas the rest rests on: plain files, the TUI and the command line
  on the same files, roots, the index, and what slipbox promises.
- [The screen](manual/screen.md): tabs, windows, the side panes, the status line, the mouse.
- [Reading](manual/reading.md): how notes and other files are drawn, pictures and diagrams among them.
- [Links and roots](manual/links-and-roots.md): the links slipbox reads and writes, and the folders they reach.
- [Finding things](manual/finding.md): the switcher, search, find and replace, the outline, history.
- [Editing](manual/editing.md): the lens and source mode, the keys, saving, completion, spelling.
- [Files](manual/files.md): the explorer: making, moving, renaming and removing files, links kept.
- [Git](manual/git.md): changes, source control, commits, blame, branches, reviewing a merge.
- [Code](manual/code.md): the code view, language servers, problems, and trusting a folder.
- [Exporting](manual/export.md): every format, and what each keeps.

For looking things up:

- [Keys](manual/keys.md): every key.
- [Configuration](manual/configuration.md): every setting and environment variable.
- [The command line](manual/cli.md): every command, its output and exit codes.

And:

- [Versions](manual/versions.md): what a version number promises, what previews are, how something is retired, and
  where to read what changed.
- [Troubleshooting](manual/troubleshooting.md): `slipbox doctor`, and the usual problems with their fixes.
