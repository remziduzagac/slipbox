# The old blog's export

nothing else. The posts never made it out as text; the closest thing to an archive is the feed in
[feed.php](feed.php), which lists them by title.

I kept the folder for the colophon, which I still like, and because the front page in [index.php](index.php) is the
last thing I wrote in PHP. Nothing here is worth moving into ~/notes.
