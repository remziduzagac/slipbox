# Photography

My photographs and what goes with them: the gear, the walks near home, the trip to Kyoto, and the exports that come out
of Lightroom. This folder is its own vault, named `photography`, so my notes reach it by pointer, and it reaches back
the same way or by a relative path.

![Harbour at dusk, the cranes lit](images/harbour-01.jpg)

## Gear

- [Lens comparison](gear/lenses.md): what each lens is for, with the catalogue codes from my insurance inventory.
- [Camera bodies](gear/bodies.md): the spec sheet I keep for every body I have owned or rented.

From anywhere in this folder the same table is [the lens comparison](/gear/lenses.md), written from its root, the way
a GitHub README writes it.
