# 京都 Kyoto, August 2026

八月二十二日から三十日まで、九日間の京都。カメラ二台（X-T5とGR）と、パソコンなしの旅だった。愛子さんが写真のキャプション
を日本語で書いてくれて、場所の名前も直してもらった。「一日に一枚、いい写真が撮れたら成功」という彼女のルールを、最後まで
守った。[^rule]

Nine days, with the X-T5 and the GR. Aiko wrote the Japanese captions and corrected my place names; the
captions here are hers, lightly edited. The plan lives in my notes, and this folder can be reached from there by the
pointer `slipbox://photography/trips/京都/index.md`, which keeps working if either folder moves.

## 朝の京都

朝六時の京都は、昼とはまるで別の街だ。鴨川の土手には犬を連れた人とジョギングの人しかいなくて、橋の上から見る東山の稜
線が、薄い霧の向こうに少しずつ色を取り戻していく。「これだ」と思った瞬間にシャッターを切ったが、あとで見返すと、手前
の鷺のほうがよく撮れていた。結局、この旅でいちばん好きな一枚は、狙わなかった一枚だった。

## 夕暮れ、そして夜

祇園の路地では、提灯の明かりが石畳に映っていた。（舞妓さんの後ろ姿は、許可を得ていないので載せない。）先斗町に入る
と、細い通りの両側に店が並び、ISO 1600でも手持ちで撮れる明るさだった。

[^rule]: 愛子さんのルール。

    一日の終わりに、その日の写真を全部見て、一枚だけ選ぶ。選べなかった日は、選べなかったと書く。

    ```text
    2026-08-24  伏見稲荷   DSCF0588   ok
    2026-08-26  錦市場     DSCF1300   ok
    2026-08-28  大原       --         選べなかった
    ```

    守れなかった日の理由は、たいてい次のどれかだった。

    - 雨で、カメラをバッグから出さなかった
    - 撮りすぎて、決められなかった
    - 食べるのに忙しかった
