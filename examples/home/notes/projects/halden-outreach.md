# Halden outreach

I volunteer at the Halden Ridge Observatory's public nights. [Dr. Lena Okafor](../people/lena-okafor.md) coordinates
us. The observatory keeps its own notes as a demo vault, a sibling of this folder: start at
[Halden's home](../../../vault/home.md) and the [outreach programme](../../../vault/outreach/index.md). The same
vault is a named one on this machine, so the refit plan can also be reached by pointer, whatever the folder is called
tomorrow: [dome refit](slipbox://halden/projects/dome-refit.md).
