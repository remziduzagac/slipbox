# API reference

> site builds from the committed copy) and ignored by the folder walk (`.gitignore` lists `docs/generated/`).

## Routes

### `GET /v1/routes`

Lists the caller's routes. Query: `limit` (default 50), `after` (cursor).

### `POST /v1/routes`

Creates a route from a polyline and a name.

### `GET /v1/routes/{id}`

One route, with its geometry.

## Shares

### `POST /v1/routes/{id}/shares`

Creates a share. See [route sharing](../features/route-sharing.md).

### `GET /v1/shares/{id}`

The shared route.

### `DELETE /v1/shares/{id}`

Revokes a share.

## Sync

### `POST /v1/sync`

Accepts a batch of ops (at most 500) and returns the server's ops since the cursor.

### `GET /v1/sync/status`

Queue depth and the number of parked ops for the caller's devices.
