# QA plan, version 2

Tomás and Jo's plan for testing the route-description renderer before 2.3. Version 1 was a list in a chat thread;
this is the file. (Its name has parentheses and a space because that is how the exporter named it, and nobody
renamed it.)

## Scope

- Route descriptions: the text riders write under a route.
- The pages in this folder, which are the test material: [links](links.md), [glyphs](glyphs.md),
  [the gauntlet](render-torture.md) and [the theme showcase](theme-showcase.md).

## How

1. Open each page in the app's description view and in the docs site.
2. Check that nothing overflows, nothing is lost and no link goes to the wrong place.
3. File anything odd with the page name and the line.
