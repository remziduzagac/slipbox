## Contents

- **Writing**: the PRD process is in `prd/plan.md`, the house style in `handbook/how-we-write.md`.
- **Previews**: every push to `main` publishes the repository as a site; the build is `mkdocs build --strict`.
- **Templates**: the PRD, release-plan and research-synthesis skeletons are the most recent file of each kind. Copy
  one rather than starting blank.
