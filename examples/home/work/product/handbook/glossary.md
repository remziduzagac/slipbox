# Glossary

The words we use the same way every time, so a PRD, a release note and a support macro agree.

| Word | Means | Not |
| --- | --- | --- |
| Rider | Anyone using Kestrel, signed in or not | User, customer |
| Route | What a rider plans | Ride, which is what they did |
| Link | A shared route's address, `kestrel.dev/s/<id>` | URL, share |
| Queue | The on-device list of changes waiting to sync | Buffer, outbox |
| Stalled | The network is up and the queue is not draining | Offline, slow |

Terms are defined once, here, and the style rules that depend on them are in [how we write](how-we-write.md#style). A
reviewer who finds a word that is not on this page uses [the review checklist](/how-we-review.md) to decide whether it
should be.
