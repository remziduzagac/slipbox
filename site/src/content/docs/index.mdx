## Your first session

slipbox reads your existing notes and code. You can use it on your own or beside an agent; no agent setup is required
for the first session.

1. [See what slipbox does](/slipbox/docs/manual/introduction/).
2. [Install it](/slipbox/docs/guides/install/) and verify the command.
3. [Try the quick start](/slipbox/docs/guides/quick-start/): open, read, edit and save a note.
4. Follow [Working with slipbox](/slipbox/docs/guides/getting-started/) for a complete tour.
5. Learn [Reading and editing in slipbox](/slipbox/docs/guides/lens/): rendered view, the lens, source mode and typing.

## Using slipbox

The **Using slipbox** sidebar group explains the screen, reading, editing, files, links, vaults, scratch, code, Git,
export and the command line. Begin with [How slipbox works](/slipbox/docs/manual/how-it-works/) for the file and vault model.

<a id="for-agents"></a>

## Help from your agent

If you want an agent to help you learn, give it the
[onboarding guide](/slipbox/docs/agent-guide/), also available as
[plain Markdown](/slipbox/docs/agent-guide.md). To operate slipbox's CLI, it should read the bundled skill from your
installed version with `slipbox skill`.
