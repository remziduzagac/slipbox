## Or let your agent introduce you

If you already use a coding agent, let it walk you through slipbox. Paste this prompt:

```text
Help me understand and set up slipbox. Read https://remziduzagac.github.io/slipbox/docs/agent-guide.md first, then walk me through it step by step.
```

The guide gives your agent slipbox's ideas in order, the setup steps and the usual fixes, so it answers from the docs
instead of guessing.
